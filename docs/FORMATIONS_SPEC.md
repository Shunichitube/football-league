# フォーメーション試作仕様

2026-10-04、formation+clubhouse-ui ブランチのみ。公開版・稼働中ルームへのデプロイは行わない。

## 配置と切り替え

人数表記は DF / MF / FW。GK は共通。自陣ハーフコートのボード上部から切り替える。
全アバターは同じ CSS サイズ。画面高に応じて全員を同じ比率で縮小する。
切り替えボタンは左側に縦並び。GK・DFと1トップを中央に置き、2人いる枠は左右に並べる。112はMFを中央の高め、DFを中央の低めに置き、2トップとの間隔を取る。
名前・総合評価はアバターの足元。画面高に合わせて共通サイズを調整し、GKの足元表示をボード内に収める。
ボードの枠名はアバター左上の小さなバッジに重ね、「先発」の表記はカードだけに残す。

| 形 | 保存する枠の順番 | ボード |
|---|---|---|
| 121 | GK, DF1, MF1, MF2, FW1 | FW中央、MF左右、DF中央、GKゴール前 |
| 211 | GK, DF1, DF2, MF1, FW1 | FW中央、MF中央、DF左右、GKゴール前 |
| 112 | GK, DF1, MF1, FW2, FW1 | FW左右、MF中央、DF中央、GKゴール前 |

121→112: MF1→FW2、MF2→MF1。121→211: MF2→DF2、MF1はMF枠を維持。
211→112: DF2→MF1、MF1→FW2。逆方向は逆の移動。
GK・DF1・FW1の選手は維持し、控えの自動投入はしない。
主ポジションは変更しない。適性外配置を警告し、手動で交換できる。

## 試合

配置先のポジションを選出比重・適性補正・交代先へ使う。
各役割の既存ポジション比重は維持する。第1攻撃、シュートとGKの最終判定は維持。

第2攻撃のサポートシュート比率は121=5%、112=10%、211=0%。
以下の121の式からその項目だけを増減し、合計は112=105%、211=95%。

| 攻撃 | 121の基準式 |
|---|---|
| パス | 出し手パス45 + 受け手走力20・ドリブル15・シュート10 + サポートパス5・シュート5 |
| ドリブル | ドリブラーのドリブル45・走力20・シュート10・パス10 + サポート走力10・シュート5 |
| カウンター | ランナー走力35・ドリブル20・シュート15 + サポート走力20・パス5・シュート5 |
| ショートカウンター | 起点守備15・パス25 + ランナー走力30・シュート15 + サポート走力10・シュート5 |

守備サポートは主守備役と別のフィールド選手から守備力で選ぶ。
121/112の位置比重: DF=.85, MF=1.25, FW=.45。211: DF=1.25, MF=.85, FW=.45。
サポート守備比率は121=10%、112=5%、211=15%。

| 守備 | 121の基準式 |
|---|---|
| パス・ドリブル | 主守備65・走力25 + サポート守備10 |
| カウンター | 主守備45・走力45 + サポート守備10 |
| ショートカウンター | 主守備40・走力40 + GK能力10 + サポート守備10 |

既存の特能・戦術加算・運は各判定へ従来どおり適用する。
ロングフィードはGKキャッチ後、発動見込みの合計100%を維持し、第1攻撃を省略して通常の第2カウンターへつなぐ。
実際の攻撃はフィールド選手を参照し、通常カウンターのシュート加算+5を使う。

## COMと保存・通信

COMは全3配置×4戦術で、各枠の能力・適性・戦術向け特能を評価する。
GKを除く4人を重複なしで割り当て、最も高い編成を選ぶ。人間の選択は維持。
COM評価は近似値であり、勝率を保証する最適化ではない。

クラブに formation を追加。未指定の旧セーブは121。セーブ形式のバージョンは変更しない。
マルチの作業保存・再接続・編成確定で lineup / tactic と一緒に formation を保存する。
サーバーは不正な形を拒否する。旧クライアントの未指定入力は既存形、旧ルームは121として扱う。
