# クラブハウスUI リファクタリング記録

対象: arena-work / dev/living-clubhouse-ui。2026-10-02。
リモートの最新状態 b66d60e を基準に、以下の整理を反映する。

## 実施内容

1. **画面描画の多段上書きを廃止** — js/app.js の render を一つにし、20画面の描画関数を screens に登録。画面描画、分類・Room状態表示、ダイアログ、タイマー・背景更新の順序を明示した。戦術と表彰は画面のHTMLに組み込み、10年終了時の履歴ボタンの重複を解消した。
2. **描画と競売開始処理を分離** — auction() から openLot を除き、startAuction() で最初のロットを開始する。ロットが欠ける場合の復旧は競売更新処理が担当する。最新UIの部分更新とCPU入札処理を維持した。
3. **ダイアログ操作を共通化** — js/dialogs.js が入場、所属選手、指名履歴、落札履歴、名前変更のEscape・Tab・背景inert・フォーカス復帰を管理する。最前面だけを閉じる。再描画時はフォーカスとスクロール位置を復元し、Room更新中も名前編集パネルを最前面に保つ。
4. **背景更新を画面更新イベントに統一** — MutationObserver と構文チェックの例外を廃止。画面の完成後に football-league:view-rendered を発火して背景を同期する。使用されなくなったクラブ情報の data 属性とJSON変換も削除した。
5. **背景寸法と競売席の座標を共通化** — js/stage-layout.js に1672×940の背景寸法と六席の配置を集約。競売HTMLの表示席とスタッフの配置を共通の値から生成し、席ごとの重複CSSを除いた。最新の全面表示会場を維持した。
6. **競売タイマーを画面に紐付け** — js/auction-clock.js が競売中だけ200msタイマーを起動し、再描画時の重複を防ぐ。画面離脱・競売終了で解除する。
7. **タイトル復帰時の初期化を統一** — js/app-state.js の createInitialState と returnToTitle に集約。ソロ・Room共通でソート、選手選択、比較、ダイアログ等の一時状態を初期化する。
8. **未使用のコードを削除** — 現行入口・モジュールから参照されない js/three-background.js、js/living-background.js を削除。未使用の stage10Players、detailPlayerId、旧描画ラッパーを削除し、import を先頭にまとめた。

配布物のキャッシュ更新用参照バージョンも更新した。ドラフト背景はフレーム開始時にCanvas合成モードを source-over に戻す。画面切り替え時には arena-fallback を解除する。

## 最新UIとの整合

手元の初回調査対象からリモートが63コミット進んでいたため、最新状態を取り込んで変更を再適用した。選手アバター、20種類の髪型、肌色・眼鏡、ドラフト選択、編成のドラッグ操作・選手比較・戦術表示を保持した。

初回調査時の「旧競売席CSS」や「900px固定ステージ」は最新UIには当てはまらない。現在使用されている .auction-desks と全面表示会場のCSSを保持し、席位置の重複だけを整理した。最新のドラフト背景は既に毎フレームのクラブJSON取得を行わない構造であり、旧背景に対する修正は持ち込んでいない。
