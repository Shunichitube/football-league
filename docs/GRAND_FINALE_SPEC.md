# 10シーズンの最終表彰・総合Pt

この文書は既存GAME_SPEC/UI_SPECへ追加する、2026-10-02合意の最終画面仕様。

## 配点

毎年リーグ1〜6位に10/7/5/3/1/0Pt。MVPは所属クラブに3Pt、TOP5は1人1Pt。重複加算する。毎年の得点王等に追加加点はしない。

10年通算の得点王、セーブ王、アシスト王、守備王、突破王、最大連勝クラブは各5Pt。同率は全員を表彰し、それぞれ満額を付与。同クラブの選手が複数受賞した場合も加算。個人賞は退団・引退選手も対象。移籍した選手の5Ptは所属時の記録割合で分配する。

守備王は守備成功数、突破王はDRIBBLEの第1/第2攻撃段階での突破成功数を使用。最大連勝はシーズンをまたいで継続し、引き分け/敗戦で停止。

資金のptと総合Ptは別。内部は小数精度を保ち、表示は小数第2位まで。総合Ptが同じなら優勝回数、通算勝点の順に比較。それも同じなら同率総合優勝。

## 演出と導線

10年目シーズン結果 → 最終表彰 → 総合結果。オンラインは10年目の結果確認完了を全員が押した後に最終表彰へ入り、視聴/退出は各自。

採用した背景の中央に、各通算表彰の記録・選手名・アバター・加算先を上から降ろす。同率表彰は全員を順番に紹介。最大連勝はクラブ名と記録を紹介する。最後は総合優勝クラブ名と総合Pt、最終シーズン終了時の全所属メンバーが降りて舞台で停止し、喜びポーズと花吹雪を表示。契約更新/退団/育成へ入る前のメンバーを使う。

1クラブ12人。2クラブは左右12人ずつ、3クラブは各6人×2段。4〜6クラブ同率の場合はクラブごとに同じ時間と演出で紹介。「次へ」「結果へスキップ」を用意し、最後は「結果を見る」で進む。BGMは今後の追加対象。

総合結果は全クラブの順位Pt/MVP/TOP5/通算表彰/合計、個人賞、各シーズンのPt内訳を表示。「シーズン詳細」は既存のクラブ実績・順位推移・シーズン別記録に接続。「ホーム画面に戻る」はタイトル画面へ。エンドロールを再生するボタンも用意。

旧保存データで存在しない記録は推測しない。移籍選手の所属別記録が不足する表彰は受賞のみ表示し、配点不能であることを明示する。単一クラブで全出場が記録されている選手は帰属が明らかなため5Ptを配点できる。
