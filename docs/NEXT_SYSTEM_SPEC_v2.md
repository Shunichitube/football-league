# FOOTBALL LEAGUE 次期システム改修仕様書 統合版 v2

Stage 19までの仕様を基礎とする追加改修。局所修正を維持し、Stage 20とStage 21を別々に実施する。

## Stage 20 — 市場・能力表示・GK調整

- 能力表示はSS〜Gの表示ランクのみで長さが決まる横型バーを併記する。同一ランク内の内部値差は表示しない。
- 新規生成される競売選手のOverall分布は F 15%、E 30%、D 30%、C 20%、B 4%、A 1%、S 0%。ドラフト候補と放出から戻る既存選手は変更しない。
- CPUは複数の空き枠でドラフトを始めた場合、原則として競売用に1枠を残す。競売では公開されるOverallランクから、同ポジションの明確な戦力アップも評価する。
- GKの通常守備評価は「GK能力×80%＋守備×10%＋走力×10%」を基礎とする。PASS攻撃ではGKのパスを5〜10%程度、ドリブルを5%程度未満のビルドアップ補助として扱う。シュートは使用しない。
- 32〜34歳のGKは各オフシーズンにGK能力だけを必ず1表示ランク低下させる。35歳引退は維持する。
