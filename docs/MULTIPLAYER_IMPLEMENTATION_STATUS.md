
```txt

season-ready

  全員確認完了したら Season 1〜9 は offseason-events へ進む
  Season 10 は game-complete で終了
```

## ドラフト・競売の組み込み方針

ロビー以降をシングルプレイ準拠にするため、ドラフト・競売も新規UIでは作らない。
既存のシングルプレイ画面を使い、マルチ側では入力状態と確定処理だけを管理する。

### ドラフト

```txt
draft
  既存のドラフト候補表示を使う
  各クラブが指名候補を選ぶ
  マルチ側で「指名済み / 未指名」を管理する
  全クラブが指名したら確定
  競合があれば抽選
  外れたクラブだけ再指名待ち
  全クラブの指名処理が終わったら次巡へ進む
```

追加する同期表示は以下だけにする。

```txt
・指名済みクラブ
・未指名クラブ
・全員指名後に確定するボタン/自動確定
・外れ指名中のクラブ表示
```

### 競売

```txt
auction
  既存の競売選手表示を使う
  各クラブが入札額または見送りを入力する
  マルチ側で「入力済み / 未入力」を管理する
  全クラブが入力したら開札
  最高額クラブが獲得
  同額なら抽選
  次の競売選手へ進む
```

追加する同期表示は以下だけにする。

```txt
・入札済みクラブ
・未入力クラブ
・全員入力後に開札するボタン/自動開札
・落札結果確認
・次の選手へ進むボタン
```

### M7: ドラフト同期レイヤー — 実装済み

- 選手整理確定時に `startNextSeason` を実行し、前年順位・シーズン番号・成績をシングル版と同じ順序で更新

- Season 1は全4巡同時指名、Season 2以降は第1巡同時／第2巡下位→上位／第3巡上位→下位／第4巡下位→上位
- 人間クラブの指名内容は `draftInputs` としてRoom内部だけに保持し、確定前の公開Room状態には含めない

- 同時指名では全対象人間クラブの入力完了後、ホストが既存 `resolveDraftActions` を1回だけ実行

- 競合時は既存抽選処理を使用し、外れクラブだけ再指名待ち
- CPUのみが残った再指名・順番指名も `draft-ready` としてホストが確定可能

- 第4巡終了後は `auction` フェーズへ進む
