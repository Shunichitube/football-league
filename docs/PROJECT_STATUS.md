## 2026-09-26 システム監査・整理

- 1試合80フェーズ、1フェーズ30秒。
- 通常攻撃は第1攻撃1フェーズ、第2攻撃＋シュート結果1フェーズ。
- CORNER / 攻撃側REBOUND回収 / SHORT COUNTER / LONG FEEDは発生時に追加消費せず、次フェーズから第2攻撃を継続。
- 80フェーズ到達時は攻撃途中でも終了。
- SAVE後20%、REBOUND回収失敗後15%でCORNER。第2PASS攻撃＋固定2、既存戦術補正を利用。
- 試合イベントログは構造化表示情報から自然文を生成し、旧ログ文字列解析互換を削除。
- 自動交代は攻撃チェーン途中では実行せず、役割情報と出場選手の不整合を防止。休養カウント自体は毎フェーズ進行。
- フィールド選手をGK起用した場合、その選手をフィールド控え候補へ重複させない。
- 引退後にGK0人またはフィールド4人未満となった場合、不足分だけ初期選手相当Gランク選手を自動補充。
- セーブ形式をversion 2へ更新し、旧セーブ互換を終了。
- セーブ画面を開いても元画面の保存禁止状態を維持。
- 旧Stage 7の重複セーブUI・イベントハンドラを削除。
- 選手ソートはポジション／総合ランク／年齢／契約年数に対応。
