# FOOTBALL LEAGUE 新試合エンジン仕様書 v1

Role-Based Match Engine / Draft

---

## 0. この仕様書の扱い

本仕様は、現在の平均値ベースの試合シミュレーションを、**役割選出型・2段階突破型の試合エンジン**へ改修するための仕様書である。

主対象は `js/sim.js` の試合計算部分。
UI、選手データ、特能名、戦術選択、スタミナ・交代システム、試合結果表示は既存仕様を活かす。

この改修は大規模変更になるため、実装時は現在状態をバックアップしたうえで、段階的に進める。
決定済みの数値・ルールは、実装中に無断で変更しない。

---

## 1. 基本思想

攻撃タイプは以下の3種類を基礎とする。

```txt
PASS
DRIBBLE
COUNTER
```

ただし、COUNTERは通常再開から常に発生する通常攻撃ではなく、主に**守備成功後に派生する速攻**として扱う。

各攻撃は原則として以下の流れで処理する。

```txt
第1攻撃
↓
第2攻撃
↓
シュート
```

シュート自体は独立フェイズとして扱わず、第2成功時に即時処理する。

---

## 2. 攻撃タイプの性格

### PASS

パス連携で崩す戦術。複数選手の能力が関与する。

主な関与者：

```txt
第1パサー
第1受け手 / 第2パサー
第2受け手
サポート役
```

### DRIBBLE

仕掛け役を中心に、サポート役と連動して崩す戦術。

主な関与者：

```txt
仕掛け役
サポート役
```

### COUNTER

守備成功後に発生する速攻。起点役、ランナー、サポート役で一気に前進する。

主な関与者：

```txt
起点役
ランナー
サポート役
```

### SHORT_COUNTER

相手の第1攻撃を大きく止めた時にだけ発生する特殊速攻。通常COUNTERよりシュート時に有利。

主な関与者：

```txt
奪取役
ランナー
サポート役
```

## 3. 再開ルール

### 3.1 通常再開

通常再開とは、落ち着いて攻撃を始める場面を指す。

対象：

```txt
キックオフ
ゴール後
枠外シュート後
GKキャッチ後
通常セーブ後
第2失敗後
カウンター非発動時
```

通常再開ではCOUNTERを出さない。

```txt
BALANCED：
PASS 50%
DRIBBLE 50%

POSSESSION：
PASS 80%
DRIBBLE 20%

DRIBBLE：
PASS 20%
DRIBBLE 80%

COUNTER：
PASS 50%
DRIBBLE 50%
```

### 3.2 守備成功後再開

守備成功後のみ、通常COUNTERが混ざる。

```txt
BALANCED：
PASS 45%
DRIBBLE 45%
COUNTER 10%

POSSESSION：
PASS 75%
DRIBBLE 15%
COUNTER 10%

DRIBBLE：
PASS 15%
DRIBBLE 75%
COUNTER 10%

COUNTER：
PASS 35%
DRIBBLE 35%
COUNTER 30%
```

### 3.3 SHORT_COUNTER優先判定

相手の第1攻撃を止めた場合のみ、守備成功後再開の前にSHORT_COUNTER判定を行う。

```txt
相手第1攻撃
↓
守備成功
↓
SHORT_COUNTER発動判定
↓
発動する：SHORT_COUNTER
発動しない：守備成功後再開
```

---

## 4. 第1成功後の第2派生

第1攻撃に成功した場合、第2攻撃へ移行する。

```txt
PASS第1成功：
PASS第2 70%
DRIBBLE第2 30%

DRIBBLE第1成功：
DRIBBLE第2 70%
PASS第2 30%

COUNTER第1成功：
COUNTER第2 100%
```

---

## 5. 第1失敗後

第1攻撃に失敗した場合、基本は相手の守備成功後再開へ移行する。

ただし、攻撃側が大きく失敗した場合、守備側にSHORT_COUNTERチャンスが発生する。

```txt
差 = 攻撃値 - 守備値

差 <= -10：
強いSHORT_COUNTERチャンス

-10 < 差 <= -4：
弱いSHORT_COUNTERチャンス

差 > -4：
SHORT_COUNTERなし
```

---

## 6. SHORT_COUNTER発動判定

SHORT_COUNTERチャンス発生時、以下の値で発動判定を行う。

```txt
counterIntent =
戦術補正
+ 守備成功補正
+ ランナー走力補正
+ サポート走力補正
+ 特能補正
+ 試合状況補正
```

### 戦術補正

```txt
COUNTER +25
BALANCED +10
DRIBBLE +5
POSSESSION -10
```

### 守備成功補正

```txt
強いSHORT_COUNTERチャンス +20
弱いSHORT_COUNTERチャンス +5
```

### 走力補正

```txt
ランナー走力補正：
ランナー走力 - 60

サポート走力補正：
(サポート走力 - 60) × 0.5
```

### 特能補正

```txt
カウンター起点 +10
スピードスター +8
```

### 試合状況補正

```txt
負けている +5
同点 0
リード中 -5
終盤リード -15
```

### 発動基準

```txt
counterIntent >= 25
```

を満たした場合、SHORT_COUNTER発動。

## 7. 戦術補正

各戦術は、該当局面に以下の補正を与える。

```txt
BALANCED：
PASS +2
DRIBBLE +2
COUNTER +2

POSSESSION：
PASS +4

DRIBBLE：
DRIBBLE +4

COUNTER：
DEFENSE +4
COUNTER +4
COUNTER_TRIGGER +4
```

補足：

```txt
COUNTERのDEFENSE +4は全守備判定に適用する。
COUNTER_TRIGGER +4はSHORT_COUNTER発動判定に反映する。
```

## 13. 役割引き継ぎルール

役割の重複・急な変更を防ぐため、以下を固定する。

```txt
PASS継続：
第1受け手 = 第2パサー

PASS → DRIBBLE：
第1受け手 = 第2仕掛け役

DRIBBLE継続：
第1仕掛け役 = 第2仕掛け役
第1サポート役 = 第2サポート役

DRIBBLE → PASS：
第1仕掛け役 = 第2パサー
第1サポート役 = 第2受け手

COUNTER継続：
第1ランナー = 第2ランナー

SHORT_COUNTER：
第1守備成功者 = 奪取役
```

---

## 14. 役割重複禁止

原則として、以下は禁止する。

```txt
第1パサー = 第1受け手
第2パサー ≠ 第1受け手 のPASS継続
仕掛け役 = サポート役
ランナー = サポート役
起点役 = ランナー
```

5人制で候補が不足する場合のみ、段階的に緩和する。

```txt
1. 完全に別選手で選ぶ
2. 第1で関わった選手の再登場は許可
3. サポート役のみ重複許可
4. 主役同士の重複は最後まで避ける
```

```txt
shotScore > gkScore：GOAL
```

## 22. 特能反映方針

特能は、チーム平均ではなく、**役割に選ばれた選手にのみ適用する**。

### GK

```txt
ショットストッパー：NORMALシュートに対してGK判定 +8%
ビッグセーバー：CLEAR / BIGに対してGK判定 +10%
ロングレンジキラー：HARDに対してGK判定 +12%
反応型：shotScoreがGK基礎判定を上回る時、GK判定 +6%
安定感：GK乱数幅を±12から±7にする
守護神：残り10分以内、同点または1点差でGK判定 +8%
```

### DF

```txt
ボールハンター：第1守備・奪取局面で守備値 +8%
カバーリング：第2守備でカバー役・最終対応DFになった時、守備値 +8%
パスカット：PASS第1カット役 +6%、PASS第2最終対応DF +8%
カウンター起点：SHORT_COUNTER発動判定 +10、COUNTER第1起点役なら起点役パス成分 +8%、SHORT_COUNTER奪取役なら奪取役パス成分 +8%
ビルドアップ：PASS第1パサー時、パス成分 +8%、COUNTER起点役時、パス成分 +5%
最終防衛線：第2守備・シュート直前守備で守備値 +8%
回復力：既存通り、ベンチ完全回復を10フェイズから7フェイズへ短縮
```

### MF

```txt
スピードスター：COUNTERランナー / SHORT_COUNTERランナー / DRIBBLE仕掛け役で走力 +8%、SHORT_COUNTER発動判定 +8
ドリブラー：DRIBBLE仕掛け役時、ドリブル成分 +10%
チャンスメイカー：PASS第2パサー / PASSサポート役時、パス成分 +8%
カットイン：DRIBBLE第2成功後、仕掛け役がシューターなら shotScore +8%
ハードワーカー：攻撃・守備で自身の走力成分 +6%
万能型：BALANCED戦術時、自身が関与する攻撃・守備の能力成分 +4%
回復力：既存通り
```

### FW

```txt
フィニッシャー：CLEAR / BIGで自身がシューターなら shotScore +10%
ミドルシューター：HARDで自身がシューターなら shotScore +10%
ポストプレーヤー：PASS第2受け手として関与時、PASS第2攻撃 +6%、PASS成功後、サポート役シュート重み +0.05
個人技：DRIBBLE仕掛け役時、ドリブル成分 +10%
勝負強さ：残り10分以内、同点または1点ビハインドで自身がシューターなら shotScore +8%
エース：シューター選出時、自身のシュート重み +20%
回復力：既存通り
```


## 26. 実装方針

一括実装ではなく、以下の段階で進める。

```txt
Stage A：
通常再開 / 守備成功後再開 / 第1→第2→シュート の骨格を実装

Stage B：
PASS / DRIBBLE / COUNTER / SHORT_COUNTER の役割選出と計算式を実装

Stage C：
シュート処理、カウンター補正、カウンター失敗デバフを実装

Stage D：
特能を役割制へ移植

Stage E：
試合統計と要約ログを整理
```

各Stageで構文エラー・進行不能・10試合連続オート停止がないことを確認してから次へ進む。

## 27. 実装時の注意

- 決定済み数値を無断変更しない。
