# GK Special Ability Spec v2

この文書は、GK特殊能力に関する現行実装の正本メモとして扱う。

`MATCH_ENGINE_SPEC_v1.md` や `INTEGRATED_ADDITIONAL_SPEC.md` に残っている旧GK特能名より、本書の内容を優先する。

## 1. 現行GK特殊能力

GKの特殊能力は以下の6種類とする。

- セービング
- 安定感
- 守護神
- スイーパーGK
- パワープレー
- ロングフィード

以下の旧GK特殊能力は使用しない。

- ショットストッパー
- ビッグセーバー
- ロングレンジキラー
- 反応型

旧4能力の役割は、基本的に `セービング` へ統合されたものとして扱う。

## 2. 表示説明

- セービング：シュート対応全般に強い。
- 安定感：GK判定のブレが小さくなる。
- 守護神：接戦の終盤でGK能力を発揮しやすい。
- スイーパーGK：相手が深く攻め込んだ場面で、GKの守備力が最終対応を助ける。
- パワープレー：終盤ビハインド時、GKが前線に加わり攻撃力を高める。攻撃失敗時はカウンターを受けやすくなる。
- ロングフィード：GKキャッチ後、前線の状況が良ければロングボールで速攻を狙う。

## 3. セービング

シュート難度に応じてGK判定へ補正する。

- HARD：補正なし
- NORMAL：GK判定 × 1.06
- CLEAR：GK判定 × 1.08
- BIG：GK判定 × 1.08

## 4. 安定感

GK判定の乱数幅を狭める。

- 通常GK：±12
- 安定感GK：±7

上限を上げる能力ではなく、良いブレと悪いブレの両方を抑える能力として扱う。

## 5. 守護神

終盤かつ接戦でGK判定へ補正する。

現行実装では以下の条件で発動する。

- 残り10分
- 同点または1点差
- GK判定 × 1.08

## 6. スイーパーGK

相手が第2攻撃へ入った場面で、守備側の第2守備値へ補正する。

- 第2守備値に `GK守備 × 0.05` を加算
- 通常GKにはこの補正なし

対象は第2攻撃判定で、PASS / DRIBBLE / COUNTER / SHORT_COUNTER に適用される。

## 7. パワープレー

### 発動条件

- 終盤
- 自チームがビハインド
- 自チームGKが `パワープレー` を持つ

条件を満たす間は自動発動する。追いついた場合やリードした場合は発動しない。

### 攻撃補正

攻撃側の第1攻撃・第2攻撃に以下を加算する。

```txt
GKパス × 0.01 + GKスピード × 0.05
```

### リスク

パワープレー中の攻撃がシュートまで到達した場合、戻り遅れリスクは発生しない。

第1攻撃または第2攻撃で止められた場合、戻り遅れリスクを持つ。

戻り遅れリスク中に相手がシュートまで到達した場合、そのシュートに対するGK判定を以下のように下げる。

```txt
GK判定 × 0.95
```

相手の攻撃をシュート前に止めた場合、その時点で戻り遅れリスクは解除する。

## 8. ロングフィード

### 発動機会

GK CATCH 後に発動機会を得る。

GKが `ロングフィード` を持たない場合は発動しない。

### 流れ

1. GK CATCH
2. ロングフィード持ちなら発動抽選
3. 発動しない場合は通常再開
4. 発動した場合はSHORT_COUNTER相当の速攻へ接続
5. 速攻突破に失敗した場合は相手通常再開

### 起点計算

ロングフィード時の起点貢献は以下を使う。

```txt
GKパス × 0.40 + GK守備 × 0.05
```

通常のSHORT_COUNTER起点とは異なる。

### 戦術補正

COUNTER戦術のカウンター系補正はロングフィードにも適用する。

### 現行実装の発動率

現行実装では、前線状況の見込み差分に応じて以下の発動率を使う。

- diff >= +10：35%
- diff >= +5：25%
- diff >= 0：12%
- diff < 0：3%

この発動率は現行実装値であり、ゲームバランス確認後に調整対象になりうる。

## 9. GK総合値

GKの総合値は以下の重みで計算する。

```txt
GK能力 70%
守備 10%
スピード 10%
パス 10%
ドリブル 0%
```

## 10. GK成長期待

GKの成長期待表示は以下だけを見る。

- GK能力
- 守備
- スピード
- パス

シュートとドリブルは、GKの成長期待表示の対象にしない。

現行の生成方針は以下。

```txt
GK能力 7
守備 1
スピード 1
パス 1
```
