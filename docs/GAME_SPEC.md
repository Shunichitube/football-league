# FOOTBALL LEAGUE — ゲーム仕様 v0.2

## 位置づけ

本書をゲームルール・計算仕様の正本とする。FOOTBALL LEAGUEは既存のPITCH LABおよびsoccer-Simulatorとは完全に別プロジェクトであり、コードや試合座標システムを共有しない。

HTML / CSS / Vanilla JavaScriptで作る、GitHub Pagesで公開可能な5人制・計算型クラブ運営ゲームである。サーバー、ログイン、ネット接続必須機能は使わない。セーブはlocalStorage、JSON Export / Importに対応する。

## 基本ゲーム

- 1人の人間クラブとCPU 5クラブ、計6クラブ。
- 10シーズン制。各シーズンはホーム&アウェー総当たり、各クラブ10試合、全30試合。
- 勝点は勝利3、引分1、敗戦0。順位は勝点、得失点差、総得点、当該成績、seeded randomで決める。
- プレイヤーの中心体験は獲得、ドラフト、オークション、育成、編成、戦術、特殊能力、契約、世代交代である。

## 禁止・対象外

フィールド座標、選手のリアルタイム移動、ボール物理、試合中操作・戦術変更、交代、スタミナ、怪我、カード、PK、セットプレー、利き足、選手間連携、給与、施設、スポンサー、オンライン対戦、選手交渉は現段階では実装しない。

## クラブとロスター

- 開始時は各クラブ5人（GK×1 / FIXO×1 / ALA×2 / PIVO×1）、全員25歳、能力はG、初期選手に特殊能力はない。
- 初期選手は通常選手より成長しにくく、放出時は市場へ戻らず消滅する。
- ロスターは5〜12人。開幕にはGKが1人以上、出場可能選手が5人以上必要。
- ポジション適性は本職100%、隣接95%、その他フィールド85%。FIXO↔ALA↔PIVOが隣接、GKは原則GK専用。フィールド選手のGK起用はGK能力50%。
- `club.lineup` はGK / FIXO / ALA / ALA / PIVOの枠順で5人を保持する。同一選手の重複とGKのフィールド枠起用は認めない。
- 人間とCPUの編成結果は共通の `SET_LINEUP` ルールで検証・反映する。適性外のフィールド配置とフィールド選手のGK起用は警告対象とし、上記の既存適性補正を試合計算へ適用する。

## 能力と表示

フィールド選手はシュート・走力・守備・ドリブル・パス、GKは加えてGK能力を持つ。内部値は50〜99で、ユーザー表示はSS/S/A/B/C/D/E/F/Gだけとし、内部値を表示しない。

| ランク | 内部値 |
| --- | --- |
| SS | 91–99 |
| S | 86–90 |
| A | 81–85 |
| B | 76–80 |
| C | 71–75 |
| D | 66–70 |
| E | 61–65 |
| F | 56–60 |

Overallは内部計算のみ。FIXOは守備35/パス25/走力20/ドリブル10/シュート10%、ALAは走力25/ドリブル25/パス20/シュート20/守備10%、PIVOはシュート35/ドリブル25/パス15/走力15/守備10%、GKはGK能力を基準とする。

## 試合の基礎計算

- 40分・30秒を1フェーズとして80フェーズ。試合開始時に全計算してよく、画面はログとして演出する。
- 通常のシーズン進行は、編成・戦術確定後の「シーズンをシミュレート」で残り全節を順番に処理する。開幕時から実行した場合は10節・リーグ全30試合となる。
- 人間クラブの各試合について、節、対戦相手、ホーム／アウェー、スコア、勝敗、選手成績、イベント、試合ごとの調子をシーズン終了後も確認できる形で保存する。
- フィールド選手4人の平均から `PossessionScore = pass×.60 + dribble×.20 + speed×.20` を求め、両者の比率で攻撃側を抽選する（最低35%、最大65%）。
- 攻撃タイプはPASS / DRIBBLE / COUNTER。戦術と特殊能力はStage 5で導入する。
- PASS: `pass×.50 + dribble×.20 + speed×.30 + luck`、DRIBBLE: `dribble×.60 + speed×.25 + pass×.15 + luck`、COUNTER: `speed×.50 + pass×.30 + dribble×.20 + luck`。守備は `defense×.70 + speed×.30 + luck`。luckは±10。
- 攻守差が-10以下は失敗、-9〜0は難しいシュート、1〜10は通常、11〜20は決定機、21以上は大決定機。
- シュート担当はシュート能力×ポジション係数（PIVO 1.30 / ALA 1.00 / FIXO .65）で抽選。`ShooterScore = shoot + ChanceBonus(-10/0/+10/+20) + luck(±12)`。
- `GoalkeeperScore = GK + saveLuck(±12) + GK_BASE_ADVANTAGE(15)`。ShooterScoreが上回ればゴール、GK-8未満ならSAVE、それ以外はMISS。
- 記録する個人成績は出場、得点、アシスト、シュート、攻撃貢献、守備成功、GKセーブ・失点、Rating。Ratingは6.0開始、得点+1.20、アシスト+.70、シュート+.05、攻撃貢献+.08、守備成功+.15、GKセーブ+.12、GK失点-.15で4.0〜10.0に制限する。
