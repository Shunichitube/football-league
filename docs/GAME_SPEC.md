# FOOTBALL LEAGUE — ゲーム仕様 v0.2

## 位置づけ

本書をゲームルール・計算仕様の正本とする。FOOTBALL LEAGUEは既存のPITCH LABおよびsoccer-Simulatorとは完全に別プロジェクトであり、コードや試合座標システムを共有しない。

HTML / CSS / Vanilla JavaScriptで作る、GitHub Pagesで公開可能な5人制・計算型クラブ運営ゲームである。サーバー、ログイン、ネット接続必須機能は使わない。セーブはlocalStorage、JSON Export / Importに対応する。

## 基本ゲーム

- 1人の人間クラブとCPU 5クラブ、計6クラブ。
- 10シーズン制。各シーズンはホーム&アウェー総当たり、各クラブ10試合、全30試合。
- 勝点は勝利3、引分1、敗戦0。順位は勝点、得失点差、総得点、当該成績、seeded randomで決める。
- プレイヤーの中心体験は獲得、ドラフト、オークション、育成、編成、戦術、特殊能力、契約、世代交代である。

## 禁止・対象外

フィールド座標、選手のリアルタイム移動、ボール物理、試合中操作・戦術変更、手動交代、怪我、カード、PK、キックイン、利き足、選手間連携、給与、施設、スポンサー、オンライン対戦、選手交渉は現段階では実装しない。

セットプレーはコーナーキックのみ実装する。GKのSAVE後20%、REBOUNDで攻撃側回収に失敗した後15%でコーナーへ移行する。コーナーは第2PASS攻撃として処理し、固定+2と既存戦術補正を適用する。

## クラブとロスター

- 開始時は各クラブ5人（GK×1 / DF×1 / MF×2 / FW×1）、全員25歳、能力はG、初期選手に特殊能力はない。
- 初期選手は通常選手より成長しにくく、放出時は市場へ戻らず消滅する。
- ロスターは5〜12人。開幕にはGKが1人以上、出場可能選手が5人以上必要。オフシーズン成長・引退後にGK不在またはフィールド選手4人未満になった場合、人間・CPUとも不足分だけ初期選手相当のGランク救済選手を自動補充する。
- ポジション適性は本職100%、隣接95%、その他フィールド85%。DF↔MF↔FWが隣接、GKは原則GK専用。フィールド選手のGK起用はGK能力50%。
- `club.lineup` はGK / DF / MF / MF / FWの枠順で5人を保持する。同一選手の重複とGKのフィールド枠起用は認めない。
- 人間とCPUの編成結果は共通の `SET_LINEUP` ルールで検証・反映する。適性外のフィールド配置とフィールド選手のGK起用は警告対象とし、上記の既存適性補正を試合計算へ適用する。

## 能力と表示

フィールド選手はシュート・走力・守備・ドリブル・パス・スタミナ、GKはシュート・走力・守備・ドリブル・パス・GK能力を持つ。GKはスタミナを持たない。内部値は50〜99で、ユーザー表示はSS/S/A/B/C/D/E/F/Gだけとし、内部値を表示しない。

| ランク | 内部値 |
| --- | --- |
| SS | 91–99 |
| S | 86–90 |
| A | 81–85 |
| B | 76–80 |
| C | 71–75 |
| D | 66–70 |
| E | 61–65 |
| F | 56–60 |
| G | 50–55 |

Overallは内部計算のみ。DFは守備35/パス25/走力20/ドリブル10/シュート10%、MFは走力25/ドリブル25/パス20/シュート20/守備10%、FWはシュート35/ドリブル25/パス15/走力15/守備10%、GKはGK能力を基準とする。

スタミナはOverallへ含めない。フィールド選手の成長、重点育成、覚醒、30歳以降のその他能力衰退の対象とする。

## 試合の基礎計算

- 40分・30秒を1フェーズとして80フェーズ。
- 通常攻撃は原則「第1攻撃」1フェーズ → 「第2攻撃＋シュート結果」1フェーズで処理する。シュート、ゴール、セーブ、守備成功などは独立フェーズを追加消費しない。
- コーナー、攻撃側が拾ったこぼれ球、ショートカウンター、ロングフィードは発生時に追加フェーズを消費せず、次フェーズで第2攻撃から再開する。80フェーズ到達時は攻撃途中でも試合終了とする。
- 役割選出、PASS / DRIBBLE / COUNTER、第1・第2攻撃、戦術補正、シュート判定の詳細は `MATCH_ENGINE_SPEC_v1.md` を正本とする。
- 通常再開はPASS / DRIBBLE、守備成功後は戦術に応じてCOUNTERを含む再開を行う。
- GK守備評価は `GK能力×80% + 守備×10% + 走力×10% + GK基礎補正 + luck` を基礎とする。
- シュート結果はGOAL / GK CATCH / SAVE / MISS / REBOUND。GK側との差が12以上ならGK CATCH、4〜11では55% SAVE・45% MISS、0〜3ではREBOUND判定を行う。
- REBOUNDの攻撃側回収率はチャンス強度とGK能力で変化する。攻撃側が回収しなかった場合のみ15%でCORNER、残りは守備側処理。
- SAVE成立時は20%でCORNER、残りは守備側通常再開。GK CATCHとMISSからはCORNERへ移行しない。
- CORNERは第2PASS攻撃を流用し、攻撃側へ固定+2。BALANCED / POSSESSION等の既存戦術補正も通常通り適用する。
- 人間クラブの各試合について節、相手、H/A、スコア、勝敗、選手成績、調子、イベントを保存する。
- 個人成績は出場、得点、アシスト、シュート、攻撃貢献、守備成功、セーブ、失点、Ratingを保持する。

## Stage 21 スタミナ・疲労・自動交代

- フィールド選手はスタミナランクに応じて100%能力を維持できる連続出場フェイズを持つ。G=12、F=13、E=14、D=15、C=16、B=17、A=18、S=19、SS=20。
- 上限超過後はフィールド5能力にだけ疲労倍率を適用する。超過1〜10フェイズは×0.90、11〜20は×0.80、21以上は×0.70。恒久能力値と表示ランクは変えない。
- ベンチへ下がったフィールド選手は通常10フェイズ休養後に完全回復する。特殊能力「回復力」を持つ場合は7フェイズで完全回復する。
- 試合開始時のDF / MF1 / MF2 / FW枠を担当枠として固定し、休養完了した元スタメンは同じ枠へ優先復帰する。控えも出場中はその枠に固定する。
- 自動交代はフィールド選手だけを対象とし、GKは原則40分出場する。控え選手は `Overall × ポジション適性` を基準に選ぶ。
- 途中出場した控えも出場として記録し、内部記録 `playedPhases` をseason/careerへ加算する。
- 特殊能力は既存24種類にフィールド専用の「回復力」を加えた25種類とする。複数所持は認めない。

## 覚醒・後天的特殊能力

- オフシーズンに18〜23歳の選手は基本3%で覚醒判定を行い、育成対象は+2%、7試合以上出場は+1%、最大6%とする。再覚醒は同確率の25%。
- 覚醒時は能力別`hiddenGrowth`を重みにして2能力を選び、各+3〜+5（上限99）。人間・CPUとも同条件、seeded randomを使用する。
- 特殊能力なしの選手は基本2%（育成対象+1%、同年覚醒+2%、最大5%）で、ポジション・今季成績・成長した能力・現在能力に対応する既存24種類のうち1つを習得できる。複数所持は認めない。

## Stage 17 復元ルール

- 24特殊能力は、本人の能力寄与・攻撃タイプ・好機・残り時間・点差などの正式条件にだけ適用する。チーム一律の補正は行わない。安定感のGK判定乱数は-7〜+7。
- Season 1は全4巡同時指名。Season 2以降は第1巡のみ同時指名、第2・4巡は前年6位→1位、第3巡は前年1位→6位で指名する。
- 順位は勝点、得失点差、総得点、当該クラブ間成績、seeded randomの順に決定する。
- 初期配布選手は放出時に消滅する。通常選手は本人情報を維持したまま、将来のオークション候補へ再登場できる。
- 年齢衰退は29〜34歳の能力別・確率別ルールを適用し、35歳で引退する。
- GKは32〜34歳の各オフシーズンに、GK能力だけを必ず1表示ランク低下させる。

## Stage 18 放出フェイズ

- オフシーズンは育成・成長・衰退、契約更新、放出フェイズ、ドラフト、競売、開幕前編成の順に進む。
- 放出は契約判断または正式な放出フェイズでのみ可能。市場開始後から競売終了までは不可とする。放出後も最低5人、GK最低1人を維持する。
- CPUも市場前に公開情報だけで必要な場合だけ戦力整理を行う。放出制限は最低5人・GK最低1人のみで、フィールドポジション不足は市場補強を前提に許可する。
- 新規生成の競売選手はF 15%・E 30%・D 30%・C 20%・B 4%・A 1%・S 0%とする。放出から戻る通常選手は能力を保持する。CPUは複数の空き枠でドラフトを始めた場合、原則として競売用に2枠を残し、競売では公開Overallランクによる同ポジションの戦力アップも評価する。

## Stage 19 記録・最終シーズン

- Best5はGK1人、DF1人、MF上位2人、FW1人の重複しない5選手とする。平均評価と5試合以上出場の条件を維持する。
- 試合成績は今季成績と通算成績の両方へ加算し、移籍・放出・引退後もリーグ側の通算記録として保持する。
- Season 10終了時は順位、表彰、historyを確定して終了する。育成、契約、放出、資金、ドラフト、競売のオフシーズン処理は行わない。

## セーブ形式

- 現行セーブ形式はversion 2。
- 旧versionのセーブ互換は維持しない。旧スロットは「旧セーブデータ（読込不可）」として表示する。
- ドラフト、競売、育成対象選択、重点育成選択の途中は保存不可。セーブ画面を開いても、元画面の保存可否を引き継ぐ。
- JSON Export / Importもversion 2のみ受け付ける。
